# 功能与验证边界

| 功能 | 当前能力 | 核查方式 / 主要边界 |
|---|---|---|
| 脉冲 LFM / 线性调频 FMCW | 分数延时、逐时隙路径、匹配滤波/FFT、连续帧 | 点目标解析位置、符号、接口等价性；不是任意体制的完整硬件仿真 |
| 平台与目标运动 | 双方三维匀速；采样平台位置、速度、四元数姿态 | 同速/相向/横向、插值和近似误差测试；时隙内部一阶路径，无传播迟滞求解 |
| 几何与面回波 | 点、点云、板、箱体、网格、程序地形、外部 DEM | 有限面积/相位/方向检查；质心漫散射或有限标量物理光学，不是全波解 |
| 静态角反射器 | 几何路径及有限次数内部镜面反射、静态 SFCW | 路径与频率响应测试；不能替代通用环境多径 |
| 阵列与角度 | SISO、SIMO、TDM-MIMO，ULA/URA/自定义坐标，RA/RAD | 通道相位、角度、TDM 等理想检查；无实测通道通用标定，模糊速度下补偿可能失效 |
| 天线与电子扫描 | 标量阵元响应、相干发射子阵、幅相加权、扫描表 | 阵列因子、主瓣/旁瓣/栅瓣检查；远场窄带、单位驱动归一化，非绝对增益 |
| 地形与遮挡 | 原始高程保留、坐标导入、Tx/Rx 分别遮挡、覆盖统计 | 独立高程网格对照；不透明表面，无衍射、穿透和一般环境多径 |
| 地物散射 | 频率/入射角/极化/类别表；显式标注测量或假设 | 禁止超出表格有效范围；分类产品不直接提供材料 RCS |
| 噪声与杂波 | ADC 白/有色高斯、距离门统计背景、复合纹理 | 统计/时序/注入域检查；不是完整标定接收机或真实海浪数字孪生 |
| 工作台 | 参数与 JSON 编辑、预检、3D、逐帧播放、RA/RD、A/B、导出 | 构建、API、浏览器操作检查；大地形仍为批处理 |
| 学习与应用 | RDA 特征、训练/推断、固定场景与跨地域研究代码 | 可选模块，不把实验成功当成回波高保真；正式验收以各次实验记录为准 |

## 公共检查

```bash
python -m pytest
python scripts/verify_configuration_matrix.py --output .runtime/matrix
python scripts/validate_motion_arrays.py --help
python scripts/validate_dynamic_surfaces.py --help
python scripts/validate_statistical_backgrounds.py --help
```

基础安装不需要 PyTorch/Numba；相应测试会明确跳过。要验证可选学习与编译加速模块，安装 `.[dev,geo,navigation]` 后重新运行全部测试，不能把基础测试通过描述为所有可选功能已验收。

## 实测迁移验证的职责

| 数据来源 | 可以支持 | 不能直接证明 |
|---|---|---|
| TSMS | 简单目标、波形与距离响应样例 | 样例与批量配置仍需核对，不作为整体通过率 |
| MAROON | 已知简单几何、静态多通道复回波 | 动态高空 RD 或复杂物体完整材料散射 |
| 玛曲 | 参考板及有覆盖范围的地表散射资料 | 任意频段、入射角或地物的散射参数 |
| IPIX | 厘米波海面距离门 I/Q 的统计谱形 | 同步海浪三维重建或陆地保真 |
| RAMP | 77 GHz 原始 ADC、通道处理、标签条件场景 | 标签不是汽车 CAD/材料，真实背景与幅度仍有差异 |
| DART | 配套几何/轨迹的局部动态场景对照 | 处理后的幅度不冒充原始 ADC；室内毫米波不证明高空厘米波 |
| Copernicus / WorldCover | 实际高程与遥感类别、几何和可见性 | 不提供同地点实测 RD 或独立材料散射真值 |

批量评价应按采集记录划分校准/开发/保留数据；同一次采集的相邻帧不是独立场景。默认展示真实结果、仿真结果、差值及 MAE，同时报告固定有效区域，避免空背景稀释误差。

没有匹配实测时，只报告解析、数值或几何证据。统计杂波比较平均功率与分布，不要求不同随机实现逐像素一致。冻结假设和随机种子，保留失败案例。
