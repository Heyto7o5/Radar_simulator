# 展示功能迭代记录

保持现有浅色工作台与深色三维视窗。展示读取已有仿真结果，物理计算模型不因展示效果而改变。

## 已确定的顺序

1. 同步回放、片段选择、视频导出及展示设置保存。
2. 镜头、布局、曲线游标、时间注释与视觉细节。
3. 章节播放列表、讲解控制、动态 A/B 对比与演示准备检查。
4. 案例预览、演示首页、素材包与离线视频图片交付。

每批改动需构建检查、浏览器实际操作与截图检查，再提交并推送 lzy-dev。

## 第一批

加入场景与结果数据就绪后的播放推进、起止帧选择、循环开关及片段末尾停止。
切帧加载期间保留上一帧画面和与其匹配的图表时间标签；时间轴显示正在同步，待场景和结果均就绪再继续播放。播放倍速仍表示展示速度。

## 第二批

工作台加入通用视频导出，使用当前三维视角与结果图，按选定片段逐帧合成。支持 720p/1080p MP4、可编辑标题与说明、每帧停留时间、生成进度、画面生成阶段取消、视频预览及封面下载。

安装可选依赖：`pip install -e '.[presentation]'`。编码需要 FFmpeg，优先使用 imageio-ffmpeg 提供的程序。生成产物存放在 `RADAR_RUNTIME_ROOT/presentations`（默认 `.runtime/presentations`），不提交到源码仓库。编码阶段最长等待 180 秒，单段最长 10 分钟、最多 600 张展示帧。

本机已实际生成并检查 1920×1080、3 秒 MP4，检查首末帧；22 项相关测试及前端生产构建通过。

展示设置持久化、镜头与布局扩展、演示编排和案例素材包仍待完成。命令行推送缺少凭据，连接器写入返回 403；当前批次仅保存本地提交，等待远端写入权限恢复。

## 回放闪烁修复

三维视图在组件生命周期内复用 Canvas、WebGL 上下文、相机及轨道控制器；帧内容在绘制前更新。结果图切帧时保留旧画面与对应元数据，移除整块闪烁遮罩。场景辅助数据与图表各缓存最近 8 个结果，缓存键包括任务和显示参数。

浏览器复现中，修复前连续播放约 2 秒移除 14 个 Canvas；修复后连续播放及四倍速播放移除数为 0，三维 Canvas 身份保持一致。已检查 1440×1000 与 467×710 布局、俯视视角保持及 MP4 导出。前端构建和工作台/展示相关测试通过。

## 序列帧数说明与编辑入口

结束帧上限继续依据实际生成结果，不采用固定 3 帧限制。回放下方显示已生成帧数、首末帧时间跨度、草稿计划帧数和帧间隔，并说明修改后需要重新运行。新增“设置序列帧数”入口，自动展开参数区并定位现有 1–100 帧输入框，移动端同样可用。不改动序列计算、预设默认值或后端限制。

前端生产构建通过。浏览器检查桌面和 467×710 手机布局、输入框聚焦、草稿帧数修改与旧结果边界保持；测试后恢复原草稿值。本批与此前回放修复均通过 SSH 推送至 lzy-dev。

## 直接生成更多帧

将回放旁的跳转入口改为直接可编辑的生成帧数和“重新生成 N 帧”按钮，复用现有检查与运行流程。播放范围明确标注为已生成帧，生成期间禁用重复操作，超出 1–100 或非整数输入不可提交。

浏览器实际生成 12 帧结果，确认结束帧最大值和值均为 12，回放推进至第 5 帧；检查手机与桌面布局、101 帧无效输入阻止提交，前端构建通过。旧任务保留原有 3 帧，不伪造或覆盖其结果。

## 结题演示：四章手动讲解

原“上一步/下一步”提示条已替换为四章导航、章节操作、任务状态卡、可展开的讲解要点与成果边界。维持浅色工作台、青绿色强调色和原三维视图。此功能仅组织已有界面与产物，不修改仿真模型。

1. 场景与配置：切到草稿预览，支持展开参数、定位场景、导出当前配置。
2. 运行与状态：展开检查区域，显示实际任务状态、完成帧数和当前草稿检查状态；可以检查草稿或复用已有结果。
3. 联动回放：切到结果视图、回到选定片段起点，默认单次播放；支持显式播放/暂停和场景/结果定位。切章时停止播放，无结果或单帧时禁用播放。
4. 成果与交付：提供实际归档、选择对比结果、复现包下载和视频面板入口。另可下载 JSON 演示摘要，记录章节、任务、配置概览、检查和播放设置。

进入演示不会自动运行或保存；退出恢复此前视图、帧位置和循环设置，保持暂停状态。自动更新在演示期间关闭且不自动重启。草稿与结果不一致时明确提示。任务未完成、无结果、检查尚未执行均展示真实状态，不用“通过”等标签替代证据。
