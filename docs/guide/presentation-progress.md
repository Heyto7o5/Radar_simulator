# 展示功能迭代记录

保持现有浅色工作台与深色三维视窗。展示读取已有仿真结果，物理计算模型不因展示效果而改变。

## 已确定的顺序

1. 同步回放、片段选择、视频导出及展示设置保存。
2. 镜头、布局、曲线游标、时间注释与视觉细节。
3. 章节播放列表、讲解控制、动态 A/B 对比与演示准备检查。
4. 案例预览、演示首页、素材包与离线视频图片交付。

每批改动需构建检查、浏览器实际操作与截图检查，再提交并推送 lzy-dev。

## 第一批

加入场景与结果数据就绪后的播放推进、起止帧选择、循环开关及片段末尾停止。
加载期间统一遮罩，避免将不同步的场景与结果显示为完整帧。播放倍速仍表示展示速度。

## 第二批

工作台加入通用视频导出，使用当前三维视角与结果图，按选定片段逐帧合成。支持 720p/1080p MP4、可编辑标题与说明、每帧停留时间、生成进度、画面生成阶段取消、视频预览及封面下载。

安装可选依赖：`pip install -e '.[presentation]'`。编码需要 FFmpeg，优先使用 imageio-ffmpeg 提供的程序。生成产物存放在 `RADAR_RUNTIME_ROOT/presentations`（默认 `.runtime/presentations`），不提交到源码仓库。编码阶段最长等待 180 秒，单段最长 10 分钟、最多 600 张展示帧。

本机已实际生成并检查 1920×1080、3 秒 MP4，检查首末帧；22 项相关测试及前端生产构建通过。

展示设置持久化、镜头与布局扩展、演示编排和案例素材包仍待完成。命令行推送缺少凭据，连接器写入返回 403；当前批次仅保存本地提交，等待远端写入权限恢复。
